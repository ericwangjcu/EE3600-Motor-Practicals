How to use this page

1. Flash the correct Practical 1 or Practical 2 UF2 firmware to the Raspberry Pi Pico.
2. Connect the Pico to the computer by USB.
3. Open this page in desktop Chrome or Edge.
4. Click Connect Pico and select the Pico serial port.
5. Select the required practical below and follow the on-screen controls.
Waiting for encoder

Encoder A → GP26, Encoder B → GP27. CPR remains adjustable so the measured output-shaft count can be calibrated.
