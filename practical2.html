Practical 2 — PID Speed Simulation

Compare open-loop and feedback control using your Practical 1 motor model. Tune the controller, track a reference and measure the response.

Simulation mode — no motor commands. All controller outputs and response graphs below are simulated. The optional Pico connection only monitors the encoder.

Use Pico motor control for the required bench speed-control task after checking the hardware guide. Position control is optional. This simulator uses percent duty / output RPM; the hardware speed loop uses fractional duty / motor RPM. For the same continuous controller, divide each simulation gain by 100 × N before hardware entry, where N is the verified motor/output speed ratio. The filters and sample times also differ, so check the implemented response. No gains transfer automatically.

1. Experiment settings

Ready. Each new run begins at rest, with the input applied at t = 1 s.

Edit values, then Apply settings. Applying during a run marks a new analysis segment. Plant gain, τ and duration are locked during a run. A new run replaces the previous recording; download it first.

Model and controller conventions

Illustrative defaults, not measured hardware: gain 2.8 rpm/% and τ = 0.35 s, with a fixed 0.08 s actuator lag. Speed is non-negative; duty is limited to 0–100% or your lower limit. The load subtracts from equilibrium speed. There is no reverse drive, electrical current model, friction, encoder noise or gearbox backlash.

Use the Practical 1 output-speed gain K in rad/s/V to obtain rpm/% = K × 60/(2π) × supply voltage/100. Copy your measured τ unchanged. PWM-to-voltage proportionality is an approximation.

Sample interval: 20 ms. u = Kp·e + ∫Ki·e dt − Kd·filtered(dy/dt). The derivative uses measurement with a 0.06 s filter. Conditional integration prevents winding up further into saturation. Mode or gain changes reset integral and derivative state; they are not guaranteed bumpless.

Measurements use only the latest unchanged segment. Settling requires at least 1 s continuously within ±2% of the segment's speed-change amplitude; later excursions revoke it. Error is reference minus mean speed over the last 2 s, shown after 3 s. It is a steady-state error estimate only if the response has stopped changing. Overshoot/settling are undefined for a zero-amplitude segment. For load-only or tuning changes, use the graph and CSV to measure recovery.
